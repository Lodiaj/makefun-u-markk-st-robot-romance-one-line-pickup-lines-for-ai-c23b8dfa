One single-line joke pickup line aimed at a robot, written for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty ($2). The program writes the line to `/output/entry.txt`.

## The line

> Are you a CAPTCHA? Because I'd prove I'm not a robot just to talk to you.

The joke is the role reversal: a human proving they are not a robot, just to talk to the machine. 73 characters, one line.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (73 bytes, no trailing newline).
